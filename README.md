# Venus OS APT Repository

This repository is intended to host APT packages and release metadata for Venus OS, a Debian-based Linux distribution.

> **Setup status:** Repository setup is in progress. No APT source line, package index, signed release metadata, or public signing-key instructions are published here yet.

## Intended use

When the repository is ready, this project will document:

- Supported Debian releases and architectures.
- Available package components and package versions.
- The repository signing key and how to verify it.
- The supported APT source configuration and update instructions.

## Safety

Do not add this repository to an APT source list or install packages from it until signed repository metadata, key verification instructions, and supported source configuration are published.

## Reporting issues

Use the issue templates to report package or repository problems. Include the package name and version, Debian release, architecture, and relevant APT output. Remove credentials and other sensitive information from logs.
